# Modular Component Library & Design System

A lightweight, high-performance UI architecture and design token system built for developer portfolios and modern web applications. 

## 🚀 Overview
This repository serves as a centralized, reusable foundation for web development projects. By enforcing strict separation of concerns (`index.html`, `styles.css`, `app.js`),
it provides plug-and-play UI building blocks designed around an **"Executive Light"** design aesthetic.

## ✨ Core Features
- **Centralized Design Tokens:** Standardized color palettes (`indigo-600`, `slate-900`, `emerald-600`, etc.) and typography scales for unified branding.
- **Interactive Component Showcase:** Fully responsive elements including action buttons, dashboard summary cards, and dynamic data tables.
- **Click-to-Copy Utility:** Programmatic clipboard integration allowing developers to inspect and copy component configuration snippets instantly.
- **Fluid Responsiveness:** Engineered with Tailwind CSS grids to scale effortlessly across mobile, tablet, and desktop viewports.

## 🛠️ Tech Stack
- **HTML5** (Semantic structure)
- **Tailwind CSS** (Utility-first styling & design tokens)
- **Vanilla JavaScript** (DOM manipulation & interactive event handling)

## 📦 Getting Started
Clone the repository and open `index.html` in any modern web browser or live server environment to explore the live component dashboard.
